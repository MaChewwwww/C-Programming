## Case Study: Bank Transaction Management System
This system allows administrators to view and filter transactions in a bank database. It supports functions like listing all transactions, filtering by account number, name, transaction date, and time, and searching for specific transaction details. Transactions are stored in a binary file (transactions.dat), and the system allows users to manage, review, and analyze transaction records.

## **Features**
- **Account Registration:** Allows new users to create an account with unique credentials.
- **Deposit and Withdrawal:** Users can add or withdraw funds with balance checks.
- **Balance Inquiry:** Users can view their current account balance.
- **Transaction History:** View transaction history in a formatted table.
- **File Handling:** Transactions are saved in a file for future reference.
- **Text Formatting:** ANSI escape codes are used for better presentation, such as color-coded outputs and bold text.
